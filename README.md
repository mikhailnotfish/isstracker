what is this?

this is a website that tracks the iss's live coordinates in real time.

the website updates every few seconds and displays the iss's current latitude, longitude, altitude, velocity, and the place it's currently flying over. i also used reverse geocoding so instead of just showing coordinates, it can tell you what country, state, city, or ocean the iss is currently above.

the ui is displayed at the bottom because i thought it looked the nicest there. the background is a picture of earth, so putting the telemetry panels near the bottom made it feel like they were part of a mission control dashboard rather than just floating randomly on the screen.

why i made this

when i joined the stardance project, i was asked to watch a youtube video explaining why hack club created it and how they partnered with nasa.

one of the things the video said, and i quote,

"the people in high school today will be the ones building the next iss in the future."



instead of making a game or something completely unrelated to space, i decided to make a website that lets anyone see where the iss is right now. i thought it was a simple idea that was still connected to the theme of the event.

the actual tracking was surprisingly easy because there is already a public api that provides the iss's live position. most of the time i spent working on this project went into designing the interface, making it update automatically, and displaying useful information in a way that was easy to read.

# features
live iss coordinates
altitude and orbital velocity
automatic updates every 5 seconds
reverse geocoding to show what the iss is flying over
responsive layout that works on different screen sizes
simple interface inspired by space mission dashboards
